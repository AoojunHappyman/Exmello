## 1. The Problem

During exam periods, university and high school students experience acute cognitive fatigue, decision paralysis, and heightened stress. When students feel overwhelmed, existing digital tools fail them:
- **Heavy Productivity Apps (Notion, Todoist, Forest):** Require meticulous setup, complex tagging, and time estimations that induce guilt and exacerbate cognitive friction.
- **Meditation Apps (Headspace, Calm):** Demand 10–20 minute passive audio commitments that students feel they "don't have time for" while in the middle of cramming.

As a result, students remain trapped in an unproductive panic loop: doom-scrolling, staring blankly at lecture notes, or giving in to test anxiety.

## 2. The Solution: EXMELLO

EXMELLO transforms the exam recovery journey into a rapid, 15-second zero-friction pipeline:

$$\text{Check In} \longrightarrow \text{Understand Need} \longrightarrow \text{Get Prescription} \longrightarrow \text{Take Action}$$

The student answers two quick visual taps:
1. **How are you feeling?** (5 emotion cards: Great, Good, Okay, Stressed, Overwhelmed)
2. **What's bothering you?** (8 contextual problem chips)
3. *(Optional)* **What do you need?** (Focus, Calm, Break, Motivated)

Within seconds, a deterministic recommendation engine provides supportive copy and launches the precise micro-action: a 25-minute quiet Pomodoro sprint, a 3-minute guided breathing circle, or a physical reset.

## 3. Key Features

- **Google Stitch Design System:** Calming palette (`#2F5D50`, `#6C8F7B`, `#A8C7B5`, `#F8F7F2`), Plus Jakarta Sans and Inter typography, soft modern wellness aesthetic.
- **3-Step Quick Check-in Wizard (`/checkin`):** Animated micro-form with keyboard support, instant progress bar, and zero mandatory typing.
- **Supportive Recommendation Hub (`/recommendation`):** Empathetic guidance copy generated by rule matrix R-01 through R-10, primary tool actions, and secondary alternatives.
- **Distraction-Free Focus Timer (`/focus`):** 15m, 25m, and 50m presets with circular SVG countdown ring, start/pause/reset, sound chime via Web Audio API, and confetti celebration.
- **Guided Respiratory Circle (`/breathing`):** Smooth Framer Motion animated expanding/contracting circle supporting **Box Breathing (4-4-4-4)** and **Physiological Sigh** modes.
- **Quick Reset Hub (`/reset`):** 60-second eye rest (20-20-20 rule timer), water & posture check, 2-minute seated desk stretches, and a private **Mental Brain Dump** with burn/release animation.
- **Evidence-Based Guides (`/resources` & `/resources/[id]`):** Micro-guides written with educational psychologists on exam anxiety, sleep consolidation, and blank page paralysis.
- **Non-Judgmental Dashboard (`/dashboard`):** Tracks completed Mindful Study Minutes without guilt streaks or red warning badges.
- **Data Privacy & GDPR Settings (`/profile`):** Local-first storage, one-click JSON data export, and complete data purge.
- **Crisis & Campus Helplines (`/help`):** Immediate 24/7 student hotlines and clear non-clinical boundaries.

## 4. Tech Stack

- **Framework:** Next.js (App Router)
- **UI Library:** React 18 + TypeScript
- **Styling:** Tailwind CSS + PostCSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Celebration:** Canvas Confetti
- **Audio:** Web Audio API (zero external sound asset dependencies)

## 5. Local Development Setup

### Prerequisites
- Node.js 18+ (tested on Node v24.19)
- npm 9+

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/AoojunHappyman/Exmello.git
cd exmello_frontend_implementation

# Install dependencies
npm install

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```

## 7. Accessibility & Ethical Commitments

- **WCAG 2.1 AA Compliant:** High-contrast text on warm alabaster (`#F8F7F2`), minimum 48px touch targets, and accessible ARIA attributes.
- **Zero Health Surveillance:** EXMELLO does not collect medical labels, student grades, or university IDs.
- **Guest-First Architecture:** All core features work locally in `localStorage` without forced registration.
- **Right to Erasure:** Full client-side data purge available in `/profile`.

## 9. Backend

The `backend/` directory contains a FastAPI + SQLAlchemy API backed by PostgreSQL. See [backend setup and API](backend/README.md) and [architecture and schema](backend/ARCHITECTURE.md). Its authenticated check-ins, rule based recommendations, focus sessions, resources, and dashboard are implemented independently of the current guest-first frontend. The frontend has not yet been wired to these endpoints and continues to use local browser data.
