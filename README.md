## 1. The Problem

During exam periods, university and high school students experience acute cognitive fatigue, decision paralysis, and heightened stress. When students feel overwhelmed, existing digital tools fail them:
- **Heavy Productivity Apps (Notion, Todoist, Forest):** Require meticulous setup, complex tagging, and time estimations that induce guilt and exacerbate cognitive friction.
- **Meditation Apps (Headspace, Calm):** Demand 10–20 minute passive audio commitments that students feel they "don't have time for" while in the middle of cramming.

As a result, students remain trapped in an unproductive panic loop: doom-scrolling, staring blankly at lecture notes, or giving in to test anxiety.

## 2. The Solution: EXMELLO

EXMELLO transforms the exam recovery journey into a rapid, 15-second zero-friction pipeline:

$$\text{Check In} \longrightarrow \text{Understand Need} \longrightarrow \text{Get Guidance} \longrightarrow \text{Take Action}$$

The student follows three short steps:
1. **How are you feeling?** (5 emotion cards: Great, Good, Okay, Stressed, Overwhelmed)
2. **What's bothering you?** (8 contextual problem chips)
3. *(Optional)* **What do you need?** (Focus, Calm, Break, Motivated)

Within seconds, a deterministic recommendation engine provides supportive copy and launches the precise micro-action: a 25-minute quiet Pomodoro sprint, a four-cycle guided breathing exercise, or a physical reset.

## 3. Key Features

- **Calm Design System:** Warm background (`#F8F7F4`), sage (`#6C8F7B` / `#A8C7B5`), peach accents, dark green accessible actions, Plus Jakarta Sans and Noto Sans Thai typography.
- **3-Step Quick Check-in Wizard (`/checkin`):** Animated micro-form with keyboard support, instant progress bar, and zero mandatory typing.
- **Supportive Recommendation Hub (`/recommendation`):** Empathetic guidance copy generated by rule matrix R-01 through R-10, primary tool actions, and secondary alternatives.
- **Distraction-Free Focus Timer (`/focus`):** 15m, 25m, and 50m presets with circular SVG countdown ring, start/pause/reset, sound chime via Web Audio API, and confetti celebration.
- **Guided Respiratory Circle (`/breathing`):** Smooth Framer Motion animated expanding/contracting circle supporting **Box Breathing (4-4-4-4)** and **Physiological Sigh** modes.
- **Quick Reset Hub (`/reset`):** 60-second eye rest, water & posture check, 2-minute seated desk stretches, and a private **Mental Brain Dump** that clears text on request without storing or uploading its contents.
- **Reading Guides (`/resources` & `/resources/[id]`):** Seeded educational articles on exam anxiety, sleep consolidation, and blank page paralysis.
- **Non-Judgmental Dashboard (`/dashboard`):** Shows real completed focus minutes, recent check-ins, activity, and a seven-day check-in strip without guilt streaks or red warning badges.
- **Data Controls (`/profile`):** Guest browser storage and account data export or deletion.
- **Crisis & Campus Helplines (`/help`):** Immediate 24/7 student hotlines and clear non-clinical boundaries.

## 5. Local Development Setup

### Prerequisites
- Node.js 24 (tested on Node v24.19)
- npm 9+

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/AoojunHappyman/Exmello.git
cd exmello_frontend_implementation

# Install dependencies
npm install

# Run the local development server
npm run dev
```

Run the PostgreSQL-backed API using the steps in [backend/README.md](backend/README.md), then open [http://localhost:3000](http://localhost:3000). The frontend defaults to `http://127.0.0.1:8000`; copy `.env.example` to `.env.local` to change `API_INTERNAL_URL`. Public articles require the API. With an account, check-ins, recommendations, and focus sessions are saved in PostgreSQL. Guest data remains in this browser and is not uploaded on sign-in.

### Production Build

```bash
npm run build
npm start
```

## 7. Accessibility & Ethical Commitments

- **Accessibility improvements:** Visible keyboard focus, labeled inputs, non-color selected indicators, buttons at least 44px high, native dialog focus handling, and reduced-motion support. A formal WCAG audit has not been performed.
- **Zero Health Surveillance:** EXMELLO does not collect medical labels, student grades, or university IDs.
- **Guest-First Architecture:** Check-ins and focus tools work without registration; articles require the public API.
- **Data Deletion:** Guests can clear browser data; signed-in users can delete their account and owned server data in `/profile`.

## 9. Backend

The `backend/` directory contains a FastAPI + SQLAlchemy API backed by PostgreSQL. See [backend setup and API](backend/README.md) and [architecture and schema](backend/ARCHITECTURE.md). The frontend is integrated with authenticated check-ins, rule-based recommendations, focus sessions, resources, and dashboard endpoints. Guest history stays local. Breathing/reset history and preferences remain browser-local for all users.
